**请评审方重点看**

1. **`clamp_level` 的边界**：`True`/`False` 返回 0（布尔不算等级），`±Infinity` 分别夹到 5/0，`NaN` → 0。15 组参数化断言覆盖。
2. **`EMPTY_PROFILE` 与「全 0 级」的区分**：`ratings={}` 才算未自评；评了全 0 是真实结论 0%，必须显示 0%。两者前端提示不同。
3. **`reports.payload` 快照**：画像删除后报告仍可读（`SET NULL`）。这是「历史报告不被改写」的实现方式。
4. **简历解析是启发式**：分句判定等级，`熟悉 JS，了解 TS` 会得到 3 与 2。它只是预填建议，不写库。
